# HASS Connect 0.7.0

Custom commands can now launch a locally selected `.bat`, `.cmd` or `.ps1` file
alongside the existing `.exe` support. Choose the file under **Controls > Custom
commands**, test it, and enable that command. Home Assistant can trigger only its
saved command name; it cannot supply script text, a path or launch options.

Scripts run as the signed-in Windows user without an elevation request. They accept no launch
options, and HASS Connect limits them to five minutes, one active run per command
and four active scripts in total. Their exit codes and timeouts appear in the local
diagnostic log. Windows PowerShell scripts follow the PC's execution policy.

This release does not add a Windows service or operation before sign-in. Existing
`.exe` custom commands and saved settings continue to work.
