# HASS Connect 0.4.1

This patch release contains all custom-command, interface and update improvements from
0.4.0, plus a shutdown reliability fix.

## Reliability fix

- Bounds the Home Assistant WebSocket close handshake so a disconnected or unresponsive
  server cannot delay application shutdown indefinitely.
- Ensures installer upgrades and removals can close the tray process reliably even when the
  notification connection is unhealthy.

See the [0.4.0 release notes](v0.4.0.md) for the complete custom-command and interface
changes, and the [custom-command guide](../custom-commands.md) for setup and security details.
