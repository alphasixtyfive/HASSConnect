# HASS Connect 0.5.0

This release adds safer Windows power controls, clearer storage settings and persistent alerts.

## What is new

- Shut down or restart the PC from Home Assistant. Both controls are off until you enable them in HASS Connect.
- Keep an important Windows notification visible by sending `persistent: true` in its Home Assistant data.
- Choose each fixed disk with one switch. HASS Connect still creates separate usage and free-space entities in Home Assistant.
- Keep previously enabled drive entities available when a disk is temporarily missing. Their state changes to `unknown` until the drive returns.

## Reliability and maintenance

- Power commands wait for their Home Assistant delivery acknowledgement before Windows begins sleeping, shutting down or restarting.
- Shutdown and restart ask Windows to close applications normally instead of forcing them closed.
- Notification, tray-icon and WebSocket cleanup is more defensive during startup, reconnects and shutdown.
- Invalid saved settings and malformed Home Assistant messages now fail cleanly instead of taking down an unrelated feature.

Existing installations keep their current choices. Enable the new shutdown and restart controls from the **Controls** page if you want to use them.

Setup examples are in the [PC command reference](../commands.md), [notification guide](../notifications.md) and [sensor guide](../sensors.md).
