# HASS Connect 0.9.1

Quick Access now holds up to 16 actions, so you can add a volume slider without
giving up a shortcut. The popup scrolls when the tiles need more room.

Any tile can be **Compact** (one column) or **Wide** (two columns). **Auto** gives
buttons one column and sliders two. Use the arrows in Quick Access settings to
put your tiles in the order you want.
