# HASS Connect 0.2.0

This release expands HASS Connect from sensors and notifications into a more complete,
opt-in Windows companion for Home Assistant.

## Highlights

- Adds microphone-in-use, webcam-in-use, battery-charging, system-disk usage and
  system-disk free-space sensors.
- Adds a dedicated Controls page with individually enabled commands for locking the
  PC, turning off displays, sleeping, media playback, mute and volume level.
- Adds a phone-friendly Home Assistant PC Controls dashboard example.
- Lets the tray shortcut open a selected Home Assistant dashboard instead of only
  the server root.
- Reliably restores and focuses the app window when it is opened from the tray or
  launched again.

## Reliability and maintenance

- Corrects 64-bit Windows input structure layout for media and mute commands.
- Enables and restores the Windows shutdown privilege required for sleep.
- Uses non-blocking display power messages and the documented Core Audio endpoint API.
- Acknowledges received commands even when parsing or execution fails, so one bad
  command cannot disconnect local push or prevent later commands from running.
- Separates command protocol, presentation, power/session control and audio/media
  control into focused components.
- Improves sensor grouping, toggle state labels, last-seen guidance and diagnostic
  error details.

PC control remains disabled by default. Review and enable only the commands you want
this device to accept.
