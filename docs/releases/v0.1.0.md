The first release of HASS Connect for Windows 11.

Choose which PC sensors appear in [Home Assistant](https://www.home-assistant.io/) and receive native Windows notifications with camera snapshots and action buttons. No MQTT broker or custom integration is needed.

Download **HASSConnect-0.1.0-Setup-x64.exe** below. Setup downloads shared Microsoft runtimes and offers to open the app when finished. An internet connection is required. This release is unsigned, so Windows may show an unknown-publisher warning. Notifications do not need a certificate import.
