# HASS Connect 0.5.1

This patch release lets Home Assistant automations choose what opens when a Windows
notification is clicked.

## Notification links

- Add `url` under the notification's nested `data` object to open a dashboard or
  web page when the notification body or image is clicked.
- Use a full HTTP(S) URL, or a Home Assistant path beginning with `/`; relative
  paths resolve against the configured Home Assistant server.
- Omit `url` to retain the existing behavior and open HASS Connect.
- Notification links use opaque, one-use activation tokens. The destination and
  Home Assistant credentials are not exposed in Windows activation arguments.
- Unsafe schemes, ambiguous paths and URLs containing embedded credentials are
  rejected. HASS Connect does not register a custom URL protocol.

Example:

```yaml
action: notify.mobile_app_desktop
data:
  title: Front door
  message: Someone is at the door.
  data:
    image: /local/front-door.jpg
    url: https://home.example/dashboard-cameras/front-door
```

See the [notification guide](https://github.com/alphasixtyfive/HASSConnect/blob/main/docs/notifications.md)
for relative dashboard paths, images, action buttons, replacement and clearing.
