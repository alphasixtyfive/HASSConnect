# HASS Connect 0.6.0

Quick access brings the Home Assistant controls you use most to the Windows tray. Set up your actions in HASS Connect, then use them without opening a browser.

## Quick access

- Add up to eight actions for lights, switches, fans, toggle helpers, scripts, scenes, buttons and covers. Cover actions follow the capabilities reported by each device.
- Give each action a name and choose from 49 searchable Segoe icons. Use the up and down buttons to set their order.
- Click the tray icon to open Quick access nearby, or set an optional keyboard shortcut to open it in the center of the screen.
- Use arrow keys to move between tiles. The popup stays open after an action, shows its current state and closes when you click away or press Escape.
- Open Home Assistant or Quick access settings from the compact footer.

The entity picker loads the full supported list, with search and type filters to help find an entity. Quick access refreshes only the states of your configured actions, so opening it stays light even with a large Home Assistant setup. Actions are unavailable while Home Assistant is disconnected.

Existing settings carry over. After updating, open **Quick access** in HASS Connect to add your first action; the keyboard shortcut is off until you choose one.

This release also improves focus, state refresh and shortcut recording after repeated popup opens. See the [Quick access guide](https://github.com/alphasixtyfive/HASSConnect#quick-access) for setup and keyboard controls.
