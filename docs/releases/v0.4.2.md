# HASS Connect 0.4.2

This release adds secure custom commands, cleans up the Windows 11 interface, and makes
updates and removal more reliable.

## What changed

- Add trusted local programs to the Controls page and run them from Home Assistant using
  fixed, reviewed options.
- Edit each custom command from a compact gear button without crowding its on/off switch.
- Update or remove HASS Connect reliably, even when its Home Assistant connection is not
  responding.
- Follow clearer setup, command, safety, and troubleshooting guides.

See the [custom-command guide](https://github.com/alphasixtyfive/HASSConnect/blob/main/docs/custom-commands.md)
for setup, examples, and safety details.
