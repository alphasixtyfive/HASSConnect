# HASS Connect 0.4.2

This release includes the new custom commands and Windows 11 interface from 0.4.0, with
more reliable upgrades and removal.

## What changed

- Adds a bounded Home Assistant connection shutdown so an unhealthy connection cannot keep
  the app open.
- Uses the Windows Installer close-application mechanism as a final fallback when the app
  does not answer a graceful shutdown request.
- Keeps the normal path graceful and only terminates the process when it does not close in
  time.
- Rewrites the public guides in clearer language and removes two low-quality screenshots.

See the [custom-command guide](../custom-commands.md) for setup, examples and safety details.
