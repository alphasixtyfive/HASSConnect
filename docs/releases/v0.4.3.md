# HASS Connect 0.4.3

This patch fixes multi-line launch options in the custom-command editor.

## Custom-command fix

- Accept Windows, WinUI and Unix line endings when reading one launch option per line.
- Prevent valid multi-line options from incorrectly showing the “Arguments must be printable” error.
- Keep every configured option as a separate literal argument when testing, saving and launching a command.

See the [custom-command guide](../custom-commands.md) for setup and troubleshooting.
