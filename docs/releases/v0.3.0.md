# HASS Connect 0.3.0

This release makes application updates direct, visible and safer while keeping the
existing opt-in controls unchanged.

## Highlights

- Checks automatically for a newer stable HASS Connect release.
- Shows an Update badge beside Settings when a new version is available.
- Downloads and opens the official Windows Setup bundle from inside the app after
  explicit confirmation.
- Displays live download progress and clear retry or fallback actions.

## Security and reliability

- Accepts update files only from the configured HASS Connect GitHub repository and
  the exact expected release path.
- Verifies the Setup bundle against its published SHA-256 checksum before running it.
- Rejects malformed versions, unexpected files, oversized downloads, incomplete
  downloads and checksum mismatches.
- Keeps partial or invalid installers out of the final update location and removes
  older cached installers after successful verification.
- Falls back to the GitHub release page when a release does not contain a complete
  Windows installer package.
- Fixes an in-flight Sensors master-toggle refresh race.

Master switches continue to act as feature gates: turning one off preserves the
individual choices underneath it, and turning it back on restores those choices.
