# HASS Connect 0.6.1

This patch adds a **Wake displays** PC command for Home Assistant. It turns on
displays that Windows has powered down while the PC is still awake.

Enable **PC control** and **Wake displays** on the Controls page, then send
`command_monitor_wake` to this device's `notify.mobile_app_*` action. The
[PC controls dashboard example](https://github.com/alphasixtyfive/HASSConnect/blob/main/docs/home-assistant/pc-controls-view.yaml)
includes a button for it.

Wake displays makes a one-time Windows display request; it does not keep the
screen on or wake a sleeping or powered-off PC. Use Wake-on-LAN for a sleeping PC.
Existing settings and the Home Assistant connection are retained by the upgrade.
