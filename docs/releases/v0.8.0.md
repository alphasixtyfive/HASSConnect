# HASS Connect 0.8.0

This release improves connection recovery and simplifies the everyday UI while
keeping the native Windows layout and rounded dialogs.

- Notifications and PC controls retry after an offline launch. Rejected credentials
  show a sign-in status instead of retrying indefinitely.
- Notification receipt is confirmed before image loading or command execution.
  Delivery stays ordered, with a bounded queue to avoid building up stale commands.
- Dashboard discovery and quick-action reads have time limits; closing the popup
  cancels obsolete requests.
- Settings keep a validated backup. Credential recovery preserves preferences,
  and interrupted connection saves can complete on the next launch. Recovering a
  backup disables PC controls until you review and enable them again.
- Sensor choices can be saved while offline or paused and are applied when reporting
  resumes. One freshness message replaces repeated status text.
- **Settings > Reset connection** lets you change servers while keeping local
  preferences. Token help opens the Home Assistant security page directly.
- Custom commands suggest a Home Assistant command name and provide a Copy button.
  Arguments stay hidden for scripts, failed saves retain your input, and rounded dialogs
  keep their action buttons visible in shorter windows.

Install this version over the previous one to retain settings and encrypted
credentials. Setup remains unsigned and downloads the required Microsoft runtimes;
no certificate import is needed.

Validation includes automated protocol and persistence tests, native Windows UI
checks, and CI installation, upgrade and removal checks. Physical suspend/resume
and end-to-end notification delivery against a live Home Assistant server were not
retested for this release.
