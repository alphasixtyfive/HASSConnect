# HASS Connect 0.4.0

This release adds secure, locally approved custom commands and refreshes the app's Windows
11 interface, installer and update experience.

## Highlights

- Add up to 20 custom Home Assistant commands that start a specific local `.exe` with fixed
  arguments.
- Test commands locally before saving, enable or disable them independently, and edit them
  from a compact gear button on the Controls page.
- Validate command names, executable paths and arguments when saving and again at launch.
- Start approved programs directly without a shell, elevation or remotely supplied
  arguments.
- Rate-limit individual and global custom-command launches.

## Interface and reliability

- Aligns cards, controls, dialogs, button placement and typography more closely with
  Windows 11 Settings.
- Keeps master switches as feature gates, preserving the individual choices underneath.
- Prevents redundant toggle updates that could cause switches to flash during refreshes.
- Places the page scrollbar in a dedicated gutter so it does not cover controls.
- Adds clearer destructive-action styling and safer delete confirmations.
- Improves automatic update discovery, progress, verification and fallback behavior.
- Keeps the Setup bundle as the single visible installed-app entry while hiding its internal
  MSI package.

See the [custom-command guide](../custom-commands.md) for configuration, security details,
Home Assistant YAML and troubleshooting.
