# HASS Connect 0.10.0

Open a live Home Assistant camera from Quick Access or a Windows notification.
Enable automatic camera popups to see who's at the door when the bell rings.
The popup can show a snapshot while the live stream connects.

Camera sound starts on and the microphone starts muted. Compatible local go2rtc
streams support two-way audio. Add buttons such as **Open gate** in each camera
tile's settings. Cover commands ask for confirmation.

Turn on **Only show while active** in Notifications to pause alerts and automatic
camera popups when Windows is locked, the display is off, or you've been idle
for five minutes.

HASS Connect runs one copy per Windows profile and starts in the tray when
launched at sign-in.

[Set up camera popups](https://github.com/alphasixtyfive/HASSConnect/blob/v0.10.0/docs/notifications.md#live-camera-notifications)
