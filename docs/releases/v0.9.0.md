# HASS Connect 0.9.0

You can now dim a light or adjust a media player’s volume right from the tray. Add
a **Brightness slider** or **Volume slider** in **Quick access**. Both get a full
row with the current percentage, so you can see the level before changing it.

Moving to another PC? Open **Transfer** in **Settings → General → Settings file**
to copy your theme, sensor choices, notification sound and quick actions. Pair the
other PC with Home Assistant separately.

There’s a new **Speaker activity** sensor under **Activity** for automations that
need to know whether Windows is playing sound. **Windows Update restart** can tell
Home Assistant when an update is waiting for a reboot. Turn on either sensor from
the **Sensors** page.

The update popup now opens with an **Update** button. If you already have that
version or a newer one, Setup tells you. Downloads are checked against the
published file size and checksum before Setup opens. **Reset connection** now sits
in the footer of the Home Assistant card.
